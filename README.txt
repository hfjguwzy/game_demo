海王遗孤(Orphan of the Deep)
========

个人向的恋爱模拟 / 视觉小说 demo，不用于商用。


项目说明
--------

《海王遗孤》打算做成一部以阅读、选择和人物关系为中心的视觉小说。
仓库目前只有宣传入口，没有可玩的正文。

index.html 同时做两件事：
  1. 作品的宣传封面
  2. 一条正在编写的设定条目

已经确定的内容写在页面上。还没拍板的地方用朱红色 TODO 标出，
之后可以直接改这些段落，不必先推翻整页。

「海王」可以是一个人、一个绰号、一处地方，也可以几层意思叠在一起。
这个词在口语里也指同时周旋于多段感情的人。用不用这层意思、用多深，都还没定。

封面暂定宣传语（可整句替换）：
  潮水会退。名字不会。

备选：
  - 你继承的不是王冠，是一串还没说完的名字。
  - 在别人的传闻里，把日子过成自己的。


现在仓库里有什么
----------------

  index.html    宣传封面，兼设定条目。用浏览器直接打开即可。
  README.txt    本说明。

页面在线时会使用思源宋体 / Fraunces；离线时回退到系统自带的宋体和雅黑。


已确定

  - 作品名：海王遗孤
  - 类型：恋爱模拟、视觉小说
  - 文字：简体中文
  - 性质：个人 demo，不商用
  - 现状：只有入口页，没有剧本、立绘和可玩章节
